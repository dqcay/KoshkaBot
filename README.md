# Кошка бот — минимальный EXE

[Скачать EXE для Windows](https://github.com/dqcay/KoshkaBot/releases/latest/download/KoshkaBot.exe)
 · [Инструкция по импорту](https://github.com/dqcay/KoshkaBot/releases/latest/download/IMPORT_INSTRUCTIONS.txt)
 · [Все релизы](https://github.com/dqcay/KoshkaBot/releases)

Отдельная Windows-версия обработки удалённых и изменённых сообщений из Dialog Spy.
В окне ввод токена, вставка из буфера, выбор папок, импорт JSON с инструкцией,
кнопка запуска и статус. Python устанавливать другу не нужно.

1. Передайте другу `dist/KoshkaBot.exe`.
2. В @BotFather создайте отдельного бота и включите Business Mode в его настройках.
3. Откройте EXE, вставьте токен через Ctrl+V (в том числе с русской раскладкой),
   Shift+Insert, контекстное меню или кнопку «Вставить».
4. Выберите папку архива чатов и, при необходимости, отдельную папку медиа.
   Выбранные папки запоминаются. Если папка медиа пустая, файлы сохраняются рядом с базой.
5. При необходимости импортируйте старые чаты до запуска: «Импорт JSON…» → `result.json`.
   Кнопка «Как получить JSON?» открывает подробную инструкцию внутри программы.
   Эта же инструкция: `dist/IMPORT_INSTRUCTIONS.txt`.
6. Нажмите «Запустить».
7. В Telegram Business → Чат-боты подключите этого бота и разрешите доступ к нужным чатам.
8. Откройте личный чат с ботом и нажмите Start, чтобы получать уведомления.

При удалении бот присылает сохранённый текст и медиа. При редактировании присылает
«Было / Стало», включая старое и новое фото или GIF. GIF Telegram передаёт как animation;
GIF, отправленный файлом, возвращается как документ. Элементы альбома отправляются отдельно.
Программа работает, пока окно открыто и компьютер подключён к интернету.

Бот сохраняет полученные входящие и исходящие сообщения подключённых бизнес-чатов.
Уведомления об удалениях и изменениях относятся к входящим сообщениям.
Старую переписку можно импортировать из экспорта Telegram Desktop в формате JSON.
Импортирует все чаты, включая группы/каналы и вышедшие чаты, которые есть в JSON;
копирует медиа, включённые в экспорт. Чаты сохраняются в читаемых `.txt` и `.jsonl`.
Импорт работает в фоне с прогрессом и отменой, потоково, без загрузки всего JSON в память.
Исходный экспорт не меняется. Повторный импорт того же JSON не дублирует записи в базе.
Отсутствующие/исключённые файлы подсчитываются отдельно. Пути вне папки экспорта не копируются.

Полный экспорт с `personal_information.user_id` того же Business-аккаунта позволяет
использовать старые личные сообщения для последующих уведомлений об удалениях/изменениях.
Текущие версии, уже полученные ботом, имеют приоритет над импортом.
Экспорт другого аккаунта и одиночные экспорты без ID владельца остаются локальными архивами.
Импорт групп/каналов не расширяет область Business-уведомлений.

Если старая версия не была получена ботом и отсутствует в подходящем импорте,
бот сообщает, что старой версии нет. Удаление неизвестного сообщения не восстанавливается.
Telegram хранит необработанные обновления не больше 24 часов.
Секретные чаты и медиа, содержимое которых Telegram не предоставляет ботам, недоступны.

Данные и очередь отправки: `<выбранная папка архива>\<ID бота>\archive.sqlite3`.
По умолчанию папка архива — `%LOCALAPPDATA%\KoshkaBot`.
Экспортированные чаты: `<папка архива>\<ID бота>\exports\<ID экспорта>`.
Медиа: `<папка медиа>\<ID бота>` или `<папка архива>\<ID бота>\media`.
При выборе новой пустой папки существующая база, импортированные чаты и медиа
копируются из последнего использовавшегося расположения; исходные файлы остаются на месте.
Настройки папок хранятся в `%LOCALAPPDATA%\KoshkaBot\settings.json`, токен туда не записывается.

Фото, GIF, видео и другие медиа новых сообщений скачиваются, когда Telegram разрешает
скачивание (обычный Bot API: до 20 МБ). Для больших/недоступных для скачивания файлов
сохраняется `file_id` для повторной отправки через Telegram. Токен остаётся только в памяти
и вводится при каждом запуске. Архив хранится локально без автоматической очистки.
После сбоя сети программа повторяет отправку. При аварии точно между отправкой и записью
результата возможно повторное уведомление — у Telegram нет ключей идемпотентности для отправки.

Не запускайте два экземпляра с одним токеном. Для друга нужен его отдельный бот:
токен действующего серверного бота нельзя одновременно использовать в EXE.
Существующие webhook-подключения программа не отключает.

Сборка из исходников: PowerShell `./build.ps1` (Python 3.12, Windows x64).
Проверка: `.venv/Scripts/python.exe -m unittest discover -s tests -v`.
